# V1.1.10 更新日志

## 全天时间块日程

按默认快捷键 `Alt+T` 打开待办日程表，即可在列表和时间轴之间切换。

1. 每天均可规划 00:00–24:00，包括周末；支持点击、拖拽创建，移动时间块和调整时长。
2. 未排期事项可拖入时间轴，覆盖统计与周回顾按全天计算；空白可一键转为备用时间。
3. 支持活动、备用、休息三种类型，以及 30/60 分钟休息和午饭预设。活动延长可消耗紧邻备用块，备用时段也可安排其他待办。
4. 每个时间块支持独立子任务清单，不自动改变父事项的完成状态。
5. “从现在重排”固定半小时锚点，保留过去和已完成的安排；剩余事项进入草稿，支持确认、取消和记录打断原因。
6. 开始计时时保存时间戳，停止、切换或完成事项时结算；提供估时建议和逐日周回顾。
7. 结束时间支持 24:00，最后半小时可完整保存。工作时段仅作背景提示，不限制全天排期。
8. 兼容原有待办数据，首次保存时间块字段前备份；保存失败保留原数据和编辑内容，读取失败阻止覆盖写入。
