## 代码分析发现

1. 待办窗口从快捷键和显式打开命令进入，两条路径分别创建 `todo` 窗口。尺寸应统一到同一个创建入口，避免修改只覆盖其中一条路径。
2. 配置在前端 `src/types/index.ts` 与后端 `src-tauri/src/models/mod.rs` 各有模型。新增设置除遵循 `AppSettings`、`DEFAULT_CONFIG`、`SettingsDialog.vue` 流程外，还要补充 Rust 字段和默认值，否则反序列化后再保存会丢失新增设置。
3. `persistenceService.backup('todos', reason)` 已实现，可以在首次保存时间块扩展字段前复用；备份失败必须阻止覆盖原数据。
4. `todoStore` 当前立即修改内存并忽略保存结果。新的日程操作需要等待保存结果、向界面反馈错误，并防止连续操作的写入顺序倒置。
5. `updateTodo` 当前在未传时间字段时也会清空时间。新增子任务、计时或块类型操作必须避免顺带修改排期。
6. `normalizeTodoItem` 已兼容旧的 `time` 字段；不能将只有开始时间的旧待办误判为完整时间块，也不能对旧数据自动取整。
7. 新建 UUID 应遵循项目约定由 Rust 生成；实现新增命令时同步注册后端处理入口。
8. 主题通过 `applyThemeSettings` 和公共颜色变量应用，时间轴需要沿用这些变量并实测亮暗主题。

## 实施顺序与验收依据

### 阶段 1：时间轴，F1–F8

- 数据计算：增加独立时间计算模块，使用分钟表示区间，以左闭右开区间计算相邻、重叠和覆盖；合并后裁剪到工作时段，避免重复计数。
- 设置：同步前后端工作日、起止时间和吸附配置，设置界面校验跨午夜、无效时段和工作日范围。
- 视图：保留月历和列表，增加时间轴、未排期池、工作时段外提示、覆盖信息及空白斜纹；完整时间块按时长渲染，旧重叠数据保留并警告。
- 交互：实现点击与框选创建、块体移动、底边调整时长、池中事项拖入；未保存或冲突时保留原计划并显示具体原因。
- 搜索：处理现有 `select-todo` 事件，选择正确日期、切换时间轴、滚动和高亮；未排期或工作时段外事项也必须可定位。
- 验收：覆盖、重叠、吸附与旧数据测试；类型检查；真实 Tauri 窗口验证拖拽、重启持久化、搜索、主题和缩放。

### 阶段 2：任务结构，F9–F12

- 以可选字段扩展现有待办实体，提供活动、备用、休息三种块类型。
- 延长活动时只消耗紧邻的备用时间，越过备用范围遇到其他安排则拒绝；备用时长归零后移除该备用事项。
- 备用剩余时段可选择未排期事项替换，替换和原备用变更在一次保存中完成。
- 详情面板提供子任务新增、删除、勾选及进度；块完成状态始终独立控制。
- 提供 30 分钟、60 分钟休息与可配置午饭预设，插入前经过同一冲突校验。
- 验收：备用块部分消耗、全部消耗、超出容量及不相邻场景测试；子任务保存和重新加载测试；类型检查与界面操作验证。

### 阶段 3：重排与打断，F13–F15

- 进入重排时固定本次锚点，当前时刻向上取整到 30 分钟；编辑期间锚点不随时钟漂移。
- 使用内存草稿承载重排，确认前不写入，取消后保持原计划。
- 锚点之前以及所有已完成事项保持不变。
- 跨越锚点的未完成事项拆为过去时段和剩余事项：原 ID、子任务与计时归属保留在剩余事项上，过去时段单独保存关联信息，避免复制 ID 或重复累计实际用时。
- 锚点之后未完成事项进入待重排池，重新摆放不得侵入固定时段；无法放入工作时段时允许明确留在池中或安排到时段外。
- 可选打断原因只用于回顾；F15 是否实现依 D5 结论决定，不擅自增加持久化类型。
- 验收：截断、已完成跨锚点、取消、重复重排、冲突、原 ID 与子任务保留测试；类型检查和真实窗口重排验证。

### 阶段 4：估时与回顾，F16–F19

- 开始计时时持久化毫秒时间戳；停止时累计差值，重开窗口或重启应用后由时间戳继续计算。
- 计时动作与其他日程修改共享保存和错误处理机制；同一时刻避免误开多个计时器，完成事项时结算正在运行的计时。
- 用有效、已结算的计时样本计算实际与估计比例的中位数；新建块时提供参考时长，样本不足时清楚说明。
- 提供本周逐日的覆盖小时、实际用时与重排次数，不增加惩罚性完成率。
- F18 是否实现依 D4 结论决定；若选择不做提醒，则不注册系统通知任务。
- 验收：多段累计、重复停止、重新加载运行中的计时、中位数奇偶样本与异常值、周起止边界测试；类型检查与真实应用隐藏、重启验证。

## 本轮代码交付与关键决策

1. **F1–F3 工作时段与时间轴**：`TodoScheduleSettings.vue` 提供工作日、起止时间、吸附步长和午饭预设；前后端设置模型同步扩展。`TodoTimeline.vue` 提供半小时行、整点标签、当前时刻线、按时长渲染和已完成灰显。快捷键与显式打开共用一个加宽窗口入口。
2. **F4–F8 日程操作**：点击、框选创建，块体移动，底边调整，未排期池拖入；详情支持手动时间。覆盖计算合并重叠并裁剪工作时段，空白斜纹可一次保存为备用块；时段外事项保留提示条。旧重叠安排可显示和编辑说明，新排期拒绝冲突。搜索读取最新保存内容，通过原事件切换到时间轴并定位。
3. **F9–F12 任务结构**：活动、备用和休息类型；延长活动占用紧邻备用块，耗尽删除，超出备用容量则提示调整后续安排。备用时段可替换为未排期事项；备用已有子任务或实际用时的用途转换会先提示记录将被移除。子任务独立增删、勾选并持久化，不自动完成父事项。支持 30/60 分钟休息及午饭预设。
4. **F13–F14 重排与打断**：锚点始终按当前时刻（包含秒数）向上取整到半小时，进入草稿后固定不漂移。过去、已完成和其他日期事项不可修改；跨锚点事项的原标识、子任务、估时与计时保留给剩余部分，过去部分用新标识和 `splitFrom` 关联。草稿编辑不写盘，确认后整份保存，取消恢复原计划；允许明确把剩余事项留在池中。原因与确认次数写入原 `todos` 数据的 `replans` 数组，未新增持久化类型。
5. **F16–F17、F19 计时与回顾**：开始计时保存毫秒时间戳，停止、切换任务或完成事项时结算；同一时刻只保留一个运行计时器。估时基准保存在 `estimatedMinutes`，重排和超时延长不改写原估时；排除运行中、备用、休息、截断片段和无效样本后取实际/估时中位数。周回顾以周一为起点，显示逐日工作时段覆盖、实际用时、重排次数与原因；实际用时归属事项日期。
6. **兼容与错误处理**：保留旧 `time`、分钟精度与可选字段。首次新格式写入前备份，成功保存才更新内存；读写进入同一队列。日程采用严格读取，读取失败阻止覆盖写入并提供重载入口。列表编辑失败保留输入；重排提交失败保留草稿。
7. **最短时长边界**：手动新建各类块至少 30 分钟。已有分钟精度的短块和重排截出的尾段可以保持原长重新摆放；自动填补短空白和消耗备用时间产生的剩余备用块允许不足 30 分钟。
8. **F15、F18**：按 D5-A、D4-A，不保存替代计划历史，不注册系统通知或提醒任务。周回顾中的确认次数和原因不包含被替代块的历史副本。
